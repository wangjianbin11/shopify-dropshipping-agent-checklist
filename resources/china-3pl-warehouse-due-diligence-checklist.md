# China 3PL Warehouse Due-Diligence Checklist

A blank operating worksheet for Shopify and ecommerce teams evaluating a China-side or destination-market warehouse before inventory moves.

Use this checklist to convert a warehouse sales conversation into evidence, ownership and testable operating decisions. A completed form is not proof by itself. Review the underlying records and test the agreed workflow with a bounded pilot.

Source guide: [China 3PL Warehouse Checklist: 15 Questions Before Moving Inventory](https://asgdropshipping.com/china-3pl-warehouse-checklist/)

## How to use this worksheet

1. Complete one copy per provider and operating site.
2. Replace verbal assurances with a named record, system field, policy or sample transaction.
3. Assign one internal owner to review each evidence item.
4. Mark unresolved items before inventory is transferred.
5. Test the agreed controls with mature SKUs before expanding scope.

Suggested decision states: `Open`, `Evidence requested`, `Evidence reviewed`, `Pilot test required`, `Accepted`, `Exception approved`, or `Rejected`.

## Fifteen control questions

| # | Control question | Evidence to request or test | Internal owner | Decision state | Notes / exception |
|---:|---|---|---|---|---|
| 1 | Which event counts as received, and which separate event makes stock sellable? | Event definitions, timestamps, sample receiving record and sellable-state transition |  |  |  |
| 2 | Who verifies inbound count and condition, and what proof is retained? | Receiving SOP, role assignment, count record, condition record and sample evidence |  |  |  |
| 3 | Which system and field own each inventory state? | System-of-record map covering in transit, received, quarantined, on hand, available, allocated and dispatched |  |  |  |
| 4 | Can every inventory adjustment be reconstructed? | Sample adjustment log with SKU, location, old quantity, new quantity, reason, time, user and linked record where available |  |  |  |
| 5 | Which event triggers each fee, and in what billing unit? | Rate card mapped to receiving, storage, handling, returns, value-added work, removal, disposal and exit events |  |  |  |
| 6 | What can change a rate, and with how much notice? | Rate-change clause, notice method, effective-date rule and exception process |  |  |  |
| 7 | What do returns, slow stock, removal and disposal cost? | Complete exception and exit fee schedule with billing units and approval points |  |  |  |
| 8 | Can the provider rebuild a sample invoice from our own data? | Sample orders, event records, rate inputs, invoice lines and reconciliation output |  |  |  |
| 9 | What documents support safety and continuity claims? | Site-specific policies, continuity plan, incident process, applicable inspection records and named owners |  |  |  |
| 10 | Which timestamps bound each service level, and how was performance calculated? | SLA start and end events, recent measurement period, numerator, denominator, exclusions and exception treatment |  |  |  |
| 11 | How are shortage, damage, mis-pick and lost parcel events classified? | Incident taxonomy, classification owner, sample case record and escalation path |  |  |  |
| 12 | Who can make a claim, under which policy, and with what limits? | Claim workflow, eligibility rules, submission window, required evidence, limits and decision owner |  |  |  |
| 13 | Which states and evidence control return-to-stock? | Return inspection states, disposition rules, evidence fields and sellable-stock authorization |  |  |  |
| 14 | What triggers a pause, move, markdown, return or disposal decision? | Aging thresholds, decision rules, approval roles, fee triggers and sample slow-stock report |  |  |  |
| 15 | How do stock, data, access and open events come back at exit? | Exit plan, inventory count, data export specification, access revocation, open-claim list, timetable and responsible owners |  |  |  |
